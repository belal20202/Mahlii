# محلي – MAHALLI
نظام إدارة المحلات والمخازن الذكي — المطور: بلال النعيمي (Belal Alnaimi) — صنع في العراق · الإصدار 1.0.0

## تشغيل محلي
flutter create . --platforms=android --project-name mahalli --org iq.mahalli
flutter pub get
flutter run

## APK
ارفع المشروع إلى GitHub (فرع main)، ثم افتح Actions > Build Android APK وحمّل mahalli-release-apk من Artifacts.
